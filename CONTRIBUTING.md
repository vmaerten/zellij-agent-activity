# Contributing

## Build and test

```sh
cargo test    # pure core, host-native, no zellij needed
cargo wasm    # release build -> target/wasm32-wasip1/release/zellij-agent-activity.wasm
task ci       # what CI runs: fmt, clippy -D warnings, test, wasm build, producer tests
```

The plugin is a pure state machine, events in and effects out, with a thin wasm-gated adapter that
runs those effects against the Zellij host. The pane to tab routing and the priority aggregation are
therefore exercised as ordinary unit tests, never in a live session. The seam is enforced by
`clippy.toml`, which disallows the host functions outside the adapter. See
[ADR-0004](docs/adr/0004-effects-seam-and-sink-abstraction.md).

Producers have their own tests, run by `task ci` too:

```sh
producers/claude/scripts/test-forwarder.sh
producers/codex/scripts/test-forwarder.sh
node --test producers/opencode/zellij-agent-activity.test.js
```

## Adding a harness

A new harness is a producer script, not a change to the wasm. It translates that harness's events
into the canonical wire vocabulary and calls `zellij pipe`. Start from
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the contract, and from an existing producer under
`producers/` for the shape. A shell forwarder where the harness runs commands, a plugin where it
doesn't.

`zellij pipe` blocks until the plugin consumes the message, so a producer without a timeout leaks
file descriptors and can take the Zellij server down with EMFILE. Every forwarder here guards with a
~5 s timeout. Keep it.

## The demo GIF

`docs/media/demo.gif` is regenerated with [`vhs`](https://github.com/charmbracelet/vhs), so it can
be redone identically when the symbols change:

```sh
task wasm && vhs docs/media/demo.tape
```

It is a staged session, the panes report their own activity on the pipe rather than running a real
agent (`docs/media/demo/agent.sh`), but the decoration is the real plugin, in `mode "rename"` so the
demo depends on nothing else.

## Conventions

- Conventional commits, no emoji: `type(scope): description`.
- Everything goes through a pull request.
- `CHANGELOG.md` is generated by [git-cliff](https://git-cliff.org) (pinned by `mise`, so
  `mise trust` on first use). Don't edit it by hand.
- Releases: `task release NEW=x.y.z` bumps, regenerates the changelog, runs CI, commits, tags and
  pushes. Pushing a `v*` tag builds the wasm and publishes it as a release asset.
- `zellij-tile` is pinned by minor, which is the plugin ABI. Moving to a new minor is an explicit
  decision: a new row in [`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md) and a new floor in the
  README.
